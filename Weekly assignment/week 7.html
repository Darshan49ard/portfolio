ProtoSem Journal - Week 07

IoT, Connectivity and Real-Time Operating Systems

This week focused on IoT, wireless connectivity, cloud communication, and Real-Time Operating Systems using the ESP32 development platform. We used the Arduino IDE to build connected applications and explored web interfaces, MQTT communication, voice commands, Firebase, and task-based programming.

What I learned

  • Programmed the ESP32 using the Arduino IDE for IoT applications.
  • Understood how a microcontroller communicates through Wi-Fi and web interfaces.
  • Developed a web-based LED control system using the ESP32.
  • Learned the fundamentals of MQTT and cloud communication.
  • Explored voice-based control for interacting with connected hardware.
  • Used Firebase for real-time data communication and smart-home applications.
  • Applied RTOS concepts including tasks, scheduling, delays, and multitasking.

Big takeaway

IoT systems connect hardware with web applications, cloud platforms, and other devices. This week showed how ESP32, wireless communication, cloud services, and RTOS multitasking work together to build responsive embedded applications.

Learning reflection

ESP32 and web-based control

I learned how the ESP32 can connect to a Wi-Fi network and act as a web server. A browser can send commands to the microcontroller through a web interface, connecting embedded programming with basic web technologies and remote hardware control.

MQTT and cloud communication

MQTT introduced me to a lightweight communication protocol used in IoT systems. Devices can publish data to topics and subscribe to topics to receive commands, allowing the ESP32 to communicate with cloud platforms and other connected devices.

Voice control and Firebase

Voice control showed how different user interfaces can be integrated with embedded systems. Using Firebase also demonstrated how cloud services can exchange data between an IoT device and an application, allowing device states to be monitored and controlled remotely.

Real-Time Operating System

I learned that an RTOS divides an embedded system into independent tasks that can be scheduled and executed efficiently. Tasks, delays, priorities, and multitasking helped me understand how more complex applications can be structured. I applied these concepts on the ESP32 by running operations such as LED control, button input, sensor monitoring, and communication independently.

Final reflection: Week 7 gave me a practical understanding of how embedded systems become connected and intelligent through IoT communication, cloud platforms, wireless connectivity, and RTOS-based multitasking. The activities helped me move beyond basic microcontroller programming and understand how real-world connected systems are designed, controlled, and managed.
